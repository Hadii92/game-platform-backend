# Block Puzzle - Game Platform Backend 
 
Backend service and web implementation of the Block Puzzle game with persistent user services. 
 
## Features 
- **Core Game Logic:** Interactive Block Puzzle implementation with session scoring. 
- **Player Services:** User ratings, comments, and high scores tracking via REST APIs. 
- **Persistence:** Relational data storage using Spring Data JPA and PostgreSQL. 
 
## Tech Stack 
- **Backend:** Java, Spring Boot, Spring Data JPA 
- **Frontend / UI:** HTMX 
- **Database:** PostgreSQL 
- **Build Tool:** Maven
